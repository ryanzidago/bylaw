# Changelog

## 0.1.0 - 2026-08-02

Initial package release.

### Added

- Add browser-independent evaluation of declarative geometry contracts from one
  coherent measurement snapshot.
- Add alignment, directional ordering and gap, overlap, containment, size,
  absolute dimension, and viewport rules for singular targets.
- Add containment, equal-width, vertical-ordering, and pairwise non-overlap
  rules for collection targets.
- Add structured reports and assertion errors with deterministic,
  machine-readable diagnostics.
- Add a validated public adapter boundary for custom measurement platforms.
- Add Playwright target resolution, snapshot collection, and explicit layout
  readiness through the `bylaw-ui/playwright` entrypoint.
